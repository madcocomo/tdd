# blog

这是一个基于 Jekyll 的个人博客。

## 本地预览

```bash
./bin/dev
```

第一次运行会自动安装依赖，然后在 <http://127.0.0.1:4000> 启动本地预览。

当前仓库固定使用 `github-pages 231`。这是这台机器上 Ruby 2.6 可稳定运行的 GitHub Pages 依赖集；如果后面你把本机 Ruby 升级到 3.x，可以再把它提升到更新版本。

## 本地检查

```bash
./bin/check
```

这个命令会构建站点，并检查首页是否已经自动聚合文章列表。

## 内容目录

- `_article/`：随笔
- `_tips/`：点滴
- `_book_review/`：读书笔记

## 新文章格式

新增文章时，只要放到对应目录，并保留最小 front matter，就会自动出现在首页：

```markdown
---
title: '文章标题'
date: 2026-05-30
---

正文...
```
