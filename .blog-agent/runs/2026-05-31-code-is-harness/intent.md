## 主旨句

软件/代码不是会被 AI 替代掉的旧媒介；在很多“AI 真正解决问题”的场景里，代码本身就是一种 harness。

它把开放式生成压进了一个可执行、可验证、可重复、可迭代的结构里。所以软件行业成为 AI 落地最快的领域，不是因为它最容易被取代，而是因为它先天就有最强的一套 harness。
